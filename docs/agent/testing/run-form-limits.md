# The new-run form's limits, refusals and seed

[← testing index](../testing.md)

Read before adding or editing tests of the new-run form's `budgetPayload.ts`, `formProblems.ts` and `formSeed.ts`. Split out of [Budgets and spend guards](budgets-and-spend.md), which holds the guards these limits configure.

`budgetFromForm` (`budgetPayload.test.ts`) is where every limit's off state is decided: `null` is the wire form of "off", so a number left in a box the operator switched off is a perfectly valid `BudgetPolicy` and starts an unattended agent under a cap nobody set, and the window pair reads 0–100 on the form against 0–1 on the wire, which makes a slip of a hundred a guard that never fires.

`runFormProblems` (`formProblems.test.ts`) is the same page's other half and the same silence: it is every reason the new-run form refuses to start, and a refusal that stops firing does not throw, does not fail a typecheck and leaves a page that looks right — it just starts the unattended agent the refusal held back. Two of them are load-bearing beyond their own sentence. The deleted-agent and the unusable-agent refusals both name the `agent` control and the page shows one problem per control via `.find`, so their push order decides which the operator reads; and `immediate` is what separates a range error, true the moment it is typed, from an emptiness error that has to wait for a blur, which is the difference between a form that argues under the caret and one that never says anything at all. The mount refusal has a sentence per kind of nowhere, and the case pins the third apart: a workspace list that could not be read is neither "No workspace is mounted", which sends the operator to `.env` over a failed request, nor "Choose", which points at a picker with nothing in it — and it refuses a mount a copied run already named, because the form cannot show where that run would go. `limitProblems` is its limit half, split out because the template Save reads it as well, and its case pins that the two give the same sentences: a Save that drifted from Start stores a limit switched on with its box blank as no limit, which the chat and the canvas then inherit. The server half of that refusal is in `templates.test.ts`, and it failed before `normalizeTemplateInput` refused `""`. `guardProblems` is its window-guard half, split out for the same Save reason with the sharper stake: a guard the Save lets through is not a missing cap, it is a wrong one — `normalizePolicy` divides anything over 1 by a hundred again, so the 150 Start refuses is stored as a 1.5% guard and parks every run the chat or the canvas inherits from the template almost at once — and its case pins that Save gives Start's own two sentences for 150 in each box and allows 1 and 100. Its server half is in `templates.test.ts` as well, and it failed before `normalizeTemplateInput` refused a window guard above 1 — the value `normalizePolicy` would fold a second time — naming the field and the value it saw. `windowGuardUnreadable` beside them is the form's forecast of the door's `no_ceiling` refusal, and its case asserts agreement with `readWindowGuard` itself rather than a restatement of it, because agreement is what drifted: the form asked whether a ceiling was set, the door asks whether the window has a fraction, and on a stock install the provider's percentage makes those two answers differ.

`formSeed.test.ts` is the same page's third door, *Start another like this*, and it earns its place on one mapping: `seedFromRun` reading a run's null `isolation` as off. `createRun` writes null only for a run that asked for a worktree and was never planned, so the copy landed on "This folder" on a git repository with nothing on the form marking it — an agent in the operator's own checkout, the failure isolation exists to prevent. The case failed on the old `=== "worktree"` reading. `"none"` copied as none and the gone-mount folder are pinned beside it because they are the two neighbours a fix to the first could plausibly break.

`budgetFromForm` now carries `maxRunTokens`, the form's token limit for a Codex run, on the same off-means-null rule, and "nothing else reaches the budget" names it — a guard field of the policy's own, so the list grew deliberately rather than loosened. The page clears the switch for every other provider before the payload is built, so a switch left on cannot cap a Claude run under a limit its form no longer shows.
