Read before adding or editing tests of `deliverRun`, `deliveryState`, the Deliver route or `delivery.ts`. Split out of [Landing, delivery and the land gate](landing-and-delivery.md) on 2026-10-06; the harness these drive is described there, under `landAfterVerify.test.ts`.

`deliverRun.test.ts` drives Deliver end to end on `landAfterVerify.test.ts`' harness, because what it pins is what reaches a remote and what the card reads back. The remote is a **local bare repository under the test's temporary directory**: `origin` reads as GitHub for `planDelivery`, `pushInsteadOf` sends the push to the bare repository and every scene asserts that rewrite first, and a stubbed `fetch` answers the one pulls endpoint and refuses any other URL. Rows carry `work_dir` = the slot as admission records it, which is why the folder-overlap guard never saw a running run. Beside two controls, a running run and one with a `waiting` link behind it are refused in `unsettledBranchRefusal`'s sentence with nothing pushed, `deliveryState` states the same sentence, `null`, `{"title": 5}` and unparseable bodies are 400s through the route, and so is `{}` for a paused run; the link survives `sweepRunEvents` and shows on the next link's card; the migration, driven by dropping the columns and reopening, backfills the newest readable event. Before the fix every case but the controls failed: both runs were pushed and opened, and `null` threw at `.title` in `pushAndOpen` after the push. Its last describe is a shutdown, last in the file because `shutdownRuns` sets a flag nothing clears: one delivery is held at its pull request after the push and another in its check, and the shutdown must not return until the first has opened and recorded its pull request, while the second is refused in its own sentence with nothing pushed; before `deliverRun` read `isShuttingDown()` and held a `trackLand` entry the shutdown returned at once, and without the second read the held delivery pushed.

Its describe on seeded files is the operator's own configuration leaving by either exit, measured before the fix on 2026-10-06 in this harness: with the seeded `.env` committed by `git add -f`, the card offered Deliver and the press pushed the operator's key, and `landRun`, refused only by the operator's copy being in the way, landed it into `main` once that copy was moved aside as `overwriteRefusal` advised. `seedEnv` copies the operator's file into the slot as `seedWorktree` would, and git's refusal of a plain `add` is asserted before the `-f`. The card and the press must refuse in one sentence naming `.env` with nothing pushed; so must a branch whose later commit untracked it, because history is what is pushed; so must one whose recorded base commit no longer exists, which without `--ignore-missing` was refused as unreadable and could never have left; so must what the card's Commit button commits from a repository that does not ignore it, `commitPending`'s `add -A` staging it; and the land must be refused before and after the move aside, with `main` at its base and no `.env` in it. All four failed before. Two controls deliver: an edit to a `.env.development` the base tracks, which is the subtraction, and the same forced `.env` once `isolationCopyGlobsByRepo` gives the repository a list not naming it, which is both the refusal's other way out and the proof the list is the repository's.

`delivery.test.ts` is the exit, and the three ways it could be wrong quietly. `parseRemote` decides *where* something is published, and getting it wrong does not throw — it opens a pull request on somebody else's repository, or refuses a perfectly good remote for having been cloned over SSH rather than HTTPS. `planDelivery` decides *whether*, and its dangerous failure is the permissive one: a plan that said yes with no token produces a push that fails half-way, and a plan that did not notice `head === base` opens a pull request with no commits in it. `readDeliveryFields` decides whether a press may start at all: the route used to cast its body, so a `title` that was not a string threw at `.trim()` after `git push` had published the branch, and its cases refuse each non-string shape by field and by what arrived while reading `{}` and an empty title as the ordinary press.
