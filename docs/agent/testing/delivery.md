`delivery.test.ts` is the exit, and the three ways it could be wrong quietly. `parseRemote` decides *where* something is published, and getting it wrong does not throw — it opens a pull request on somebody else's repository, or refuses a perfectly good remote for having been cloned over SSH rather than HTTPS. `planDelivery` decides *whether*, and its dangerous failure is the permissive one: a plan that said yes with no token produces a push that fails half-way, and a plan that did not notice `head === base` opens a pull request with no commits in it. `parseRemote` refuses `http://` too, which publishes unencrypted, and `planDelivery` is handed the push URLs and must refuse an SSH spelling still standing after the rewrites, none, and more than one. `readDeliveryFields` decides whether a press may start at all: the route used to cast its body, so a `title` that was not a string threw at `.trim()` after `git push` had published the branch, and its cases refuse each non-string shape by field and by what arrived while reading `{}` and an empty title as the ordinary press.

`projectPush.test.ts` drives `pushProject`, `fetchProject` and `projectInventory` against real repositories, because what it pins is what reaches a remote. Every remote is a genuine `https://github.com/acme/<name>.git`, and git's https transport is replaced for the process: `GIT_EXEC_PATH` names a copy of git's exec directory whose `git-remote-https` answers the remote-helper protocol with `connect` and hands the connection to a local bare repository, so nothing reaches GitHub, no credential is asked for, and the URL the decision reads is the real shape. Every other way of pointing a GitHub-looking URL at a local path is one the push check refuses, which is why it is done this way; each scene asserts the URL and that its first push reached the bare repository. The process's own `GIT_*`, `GH_*` and `GITHUB_*` variables are deleted before the first import and global config is `/dev/null`, because an agent's shell carries a real token and URL rewrites.
