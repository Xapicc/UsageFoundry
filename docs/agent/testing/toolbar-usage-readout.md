# The toolbar's usage readout

[← testing index](../testing.md)

Read before adding or editing tests of `usageRemaining.ts` or of `UsageRemaining.tsx`'s `remainingStrip`.

`usageRemaining.test.ts` is the route's mapping from the two provider caches to what the shell is told, and it fails quietly in three places. A provider with no stored sign-in drawn as one that is — the caches outlive a sign-out, so a held plan with `signedIn: false` must still be absent. A window with no current reading drawn as a number: at 0% used it reads "plenty left" and at 100% "spent", and the closed-window case is the one that arrives with no fault anywhere, because `planUsage` re-serves its last good reading on age alone and a window can close inside that hour. And a reading the provider has stopped refreshing presented as current: `REFRESH_MS` exactly is fresh and one millisecond past it is stale, because the cache refreshes on any call past it, so a reading served older than that is one whose refresh failed. The Codex case pins why `currentPlanReading` is not reused for it — a day-long primary window with twenty hours to run is live, and that function's five-hour session test would call it closed. The over-the-wall figure passes through uncapped, as `planUsage.ts` keeps it.

`UsageRemaining.test.ts` is the strip's side of the same answer, on the same grounds, and renders nothing — it tests exported pure functions, which is why it is a `.test.ts` and the count of renderings in `testing.md` is unchanged. "Left" is one minus used clamped to 0–1, and an unknown stays null through the subtraction rather than becoming 100%; an unknown has no severity, which is not the "ok" `severityFor(null)` returns, so it must not be tinted as fine; severity is read off the used fraction at the same 70% and 90% every meter uses; a wall the provider says is hit reads danger over a window that shows less; and a failed poll turns every held figure to a dash, because the last answer can no longer be vouched for. The accessible name is asserted to open with the words on screen — a voice command naming "Claude 5h" has to land on it — and to carry the resets after them.
