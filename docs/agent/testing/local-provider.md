# The local provider

[← testing index](../testing.md)

Read before adding or editing tests of `localProvider.ts`, `localCertification.ts`, or the gate `landState` and `deliveryState` put in front of a local model's branch.

`localProvider.test.ts` pins `localCycleEnv`, the one place a local cycle stops being a Claude cycle, and both of its failures are silent in the worst direction. Leave `ANTHROPIC_BASE_URL` alone and the cycle goes through winnow's proxy to Anthropic, under a model id Anthropic does not have or — worse — on the operator's plan; leave an Anthropic credential in place, or leave `ANTHROPIC_AUTH_TOKEN` unset so the CLI falls back to the OAuth login, and the subscription credential is sent to whatever server the base URL names. Neither throws. So it asserts the base URL, the token, the config directory and all six model roles are set, that every credential and routing variable on `LOCAL_STRIPPED` is gone — including the OTLP ones, which would report a price the CLI made up — that the placeholder token is set when the server wants none, and that the Claude environment it was handed is not mutated. `parseLocalSignIn` earns cases on what it must refuse: a pasted `…/v1`, which is a 404 at the first cycle that names nothing; a credential in the URL, which the page would read back; and a model id that would not survive argv, a leading dash included. `probeLocalEndpoint` is pinned on the OpenAI-shaped 200 it must not accept, because that server answers a model list and fails every cycle.

`localCertification.test.ts` is the decision: the verdict parser on the hedges it must read as no verdict ("APPROVE with caveats", a verdict inline in another section, an echoed instruction above the real answer), the frontier predicate on a Haiku and an unplaced id, and `certificationRefusal` on every state an approval can be stale in — running, failed, no commit recorded, a rejection, no clear verdict, a non-frontier model, and above all a branch that moved after the review, which is the one a person is least likely to notice.

`localLandGate.test.ts` is `loopMergeOwnership.test.ts`' harness — a database, a real repository, `DATA_DIR` named before the first import — for the one question the unit file cannot ask: whether the decision is ever put. A `landState` reading the wrong review, the wrong tip, or a Deliver path that skipped the check would leave every unit case green and the button working. It writes the run and review rows the way the app does, commits on the branch, and asserts Land and Deliver refuse with no review, open on an approval of the tip, close again when the tip moves, stay closed on a rejection, hold a Claude run that shares a local run's branch, and ask nothing of a branch only Claude worked on.

`credential-audit.test.ts` covers `/api/local-provider` as a seventh credential route — see [auth-config-and-status-routes.md](auth-config-and-status-routes.md) — with a stub HTTP server as the endpoint, since the route probes before it saves.

`reviewBlock.test.ts` pins a workflow review block's decisions one step at a time — the same strict verdict, a fix round only while rounds are left, never one on a block with none, set aside after the last with the tasks marked, and a review that could not run or a fix the operator stopped set aside *without* marking anything, because neither is a judgement on the model. `workflows.test.ts` carries what the scheduler hands on past one: the fix run the review approved rather than the attempt it rejected, an approved branch whose run asked for review, nothing — and a merge that still settles — when every branch was set aside, and a merge blocked behind a review block that failed; and, in the same file, the save-time rules for `provider` and `fixRounds` and the provider half of `planNode`. `canvasGraph.test.ts` has `worstCaseRuns` counting a review member's fix runs.

`reviewBlockRun.test.ts` is `localLandGate.test.ts`' harness with a stand-in for `claude` — a script that approves a brief carrying a marker and rejects the rest, printing the `stream-json` result a review ends with — for what no pure test can see: that the block, handed two branches, asks each for a verdict, records the tip it was shown, hands on only the approved one, lands the reviews' cost on its own row, and marks and comments the rejected branch's task. Every one of those fails silently, and the first as a merge of work nobody approved.
